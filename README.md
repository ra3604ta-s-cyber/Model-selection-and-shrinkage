# Sleep Duration Prediction

This project predicts `Sleep_Duration` using the provided sleep dataset.

## Methods

Three models were compared:

- Linear Regression
- Lasso Regression
- Random Forest

Lasso was used as the **shrinkage method** for model selection. The models were compared using validation **Mean Squared Error (MSE)**.

Random Forest was used for the final Kaggle prediction.

## Files

- `sleep_duration_model_selection_Ran_Tao_2026.ipynb` – analysis and code
- `train.csv` – training data
- `test.csv` – test data
- `submission.csv` – Kaggle submission
